# kartinkomet

Telegram-бот для случайных картинок, общего пула, пакетной загрузки, реакций, дуэлей, достижений и мемного хаоса.

[English README](README.en.md)

## Что это

`@kartinkomet_bot` - бот для Telegram-групп и каналов. Он отправляет случайные изображения из общего пула по кнопке `🎲 Рандом` или команде `/pic`.

Бот не хранит сами картинки на сервере. Он сохраняет только Telegram `file_id`, а физические файлы остаются на стороне Telegram.

## Главное

- общий пул изображений для всех чатов
- загрузка доступна всем участникам
- slash-команда загрузки только одна: `/upload_pidor`
- изображения не скачиваются на сервер
- дубликаты отсекаются по Telegram `file_unique_id`
- загрузка ограничена лимитом `100` новых пикч от одного пользователя в час
- рандом помнит недавние выдачи по каждому чату
- один пользователь может поставить только одну реакцию на картинку, но может перевыбрать её
- при `2 🖕` картинка удаляется из пула народным судом
- достижения выдаются за личный вклад в пул
- `/me` показывает титул качества, реакции на ваши пикчи и комбо-достижения
- `/top` показывает топ загрузчиков
- `/duel` запускает минутную дуэль двух случайных пикч, проигравшая удаляется
- `/reset_stats` защищён через `ADMIN_USER_IDS`
- скрытая админ-команда `/dedupe_user USER_ID` убирает точные дубли от конкретного пользователя
- отдельный скрипт чистит визуальные дубли через `dHash`
- на обычный текст или тег без команды бот молчит

## Команды и кнопки

| Команда или кнопка | Что делает |
| --- | --- |
| `🎲 Рандом`, `/pic` | Отправляет случайную пикчу |
| `⚔️ Дуэль`, `/duel` | Запускает минутную дуэль двух случайных пикч |
| `🎲 Ещё` | Запрашивает следующую пикчу под текущей |
| `⬆️ Загрузка`, `/upload_pidor` | Открывает режим загрузки |
| `👤 Мой вклад`, `/me` | Показывает ваш вклад и достижения |
| `🏆 Топ`, `/top` | Показывает топ загрузчиков |
| `📊 Статы`, `/stats` | Показывает пул, выдачи и реакции по блокам |
| `✅ Закончить`, `/done` | Завершает загрузку и показывает итог |
| `❌ Отмена`, `/cancel` | Отменяет активную загрузку |
| `/count` | Показывает количество пикч в пуле |
| `/mood` | Показывает режим бота на сегодня |
| `/menu` | Открывает пульт от ядерки |
| `/help` | Показывает список команд |

`/upload` намеренно не существует. Загрузка открывается через кнопку или только через `/upload_pidor`.

## Рандом

Рандом не просто берёт случайный элемент из списка. Алгоритм делает несколько шагов:

1. Убирает картинки, которые недавно показывались в текущем чате.
2. Убирает глобально свежие выдачи по всему пулу.
3. Отдаёт приоритет картинкам с меньшим количеством показов.
4. Выбирает итоговую пикчу через `SystemRandom`.

Если картинок много, повторов становится заметно меньше. Если картинок мало, повторы возможны, но бот старается не крутить одну и ту же пикчу подряд.

## Дуэли

`/duel` выбирает две случайные пикчи, отправляет их одним альбомом без подписей под фотографиями, а затем открывает голосование на `60` секунд.

Для дуэлей есть `222` отдельные фразы: анонсы боя и финальные вердикты. Поэтому битвы выглядят живее и меньше повторяются, а фото остаются чистыми.

Правила:

- каждый пользователь может голосовать один раз, но может перевыбрать сторону
- после таймера бот объявляет результат
- проигравшая пикча удаляется из пула
- при ничьей обе пикчи остаются
- под итогом появляется кнопка `⚔️ Новая дуэль?`

## Загрузка картинок

1. Нажмите `⬆️ Загрузка` или отправьте `/upload_pidor`.
2. Отправьте одну картинку, несколько картинок подряд, альбом Telegram или пересланные изображения.
3. Когда закончите, отправьте `/done`.

Бот не пишет отбивку на каждую принятую картинку. После первой успешной картинки он один раз подтверждает, что пакет принимается, и показывает кнопки `✅ Закончить` и `❌ Отмена`.

Если нажать старую кнопку после закрытия загрузки, бот не спамит чат повторными итогами. Он просто отвечает коротким уведомлением в интерфейсе Telegram.

Если файл не является изображением, бот не добавляет его в пул. Если картинка уже была в пуле, она считается дубликатом и пропускается.

Лимит защиты от заливочных скриптов: один Telegram user ID может добавить не больше `100` новых пикч за час. Дубликаты и ошибки лимит не тратят.

## Группы и Privacy Mode

В Telegram-группах обычные фото могут не доходить до бота, если включён BotFather Privacy Mode.

Лучший вариант:

1. Откройте `@BotFather`.
2. Выполните `/setprivacy`.
3. Выберите `@kartinkomet_bot`.
4. Выберите `Disable`.

Если Privacy Mode оставлен включённым, открывайте загрузку и прикрепляйте картинки ответом на сообщение бота. Поэтому бот отправляет отдельное ForceReply-сообщение в группах.

## Каналы

Для каналов бот должен быть администратором с правом отправлять сообщения и медиа.

Надёжная схема:

1. Загружать картинки в личке с ботом или в отдельной админ-группе.
2. Указать `TARGET_CHANNEL_ID`.
3. Вызывать `/pic`, чтобы бот публиковал картинку в привязанный канал.

## Реакции

Под каждой картинкой есть:

- `👍`
- `💩`
- `🖕`

Правила:

- один пользователь даёт один голос на одну картинку
- пользователь может изменить реакцию
- голоса разных пользователей складываются
- накрутка одним человеком не работает

Народный суд:

- `1 🖕` - бот молчит
- `2 🖕` - картинка удаляется из пула, а сообщение об удалении отправляется ответом на неё

## Тексты

Все большие наборы фраз лежат в `bot/texts.py`.

Сейчас внутри:

- `1500` caption-фраз для картинок
- `150` стартовых фраз загрузки
- `150` фраз завершения загрузки
- `150` фраз пустого пула
- `50` достижений
- ежедневные mood-режимы
- правила народного суда

Caption под картинкой чистый. Старые mood-префиксы удалены.

## Достижения

Бот выдаёт достижения за количество загруженных пикч конкретным пользователем.

Формат:

```text
🏅 Достижение: первый вброс
@username загрузил пикч: 1
```

В реальном сообщении слово `Достижение:` выделяется жирным.

Команда `/me` показывает:

- сколько пикч загрузил пользователь
- текущее достижение
- сколько осталось до следующего достижения
- титул качества по реакциям на его пикчи
- комбо-достижения за реакции, показы и активность

Команда `/top` показывает топ загрузчиков. Если бот уже видел пользователя, он покажет `@username` или имя из Telegram. Для старых записей без сохранённого профиля останется Telegram user ID, пока человек снова не нажмёт команду или кнопку.

## Статистика

`/stats` показывает:

- блок `📦 Пул`: сколько пикч внутри
- блок `🎲 Рандом`: сколько раз бот выдавал картинки
- блок `🧪 Реакции`: сколько поставили `👍`, `💩` и `🖕`

Служебная команда `/reset_stats` сбрасывает реакции, показы и память рандома. Она не показывается в меню команд и доступна только пользователям из `ADMIN_USER_IDS`.

## Чистка визуальных дублей

Если одинаковые картинки были загружены как разные файлы, Telegram может выдать им разные `file_unique_id`. Встроенная проверка точных дублей такие случаи не поймает.

Для этого есть отдельный maintenance-скрипт:

```bash
python scripts/visual_dedupe.py --user-id 1045485205 --dry-run
```

По умолчанию скрипт читает `/data/image_pool.json`, скачивает изображения из Telegram, считает визуальный `dHash` и показывает найденные похожие дубли без изменения базы.

Когда отчёт выглядит нормально, можно применить чистку:

```bash
python scripts/visual_dedupe.py --user-id 1045485205 --apply
```

Перед изменением базы скрипт создаёт backup рядом с `image_pool.json`. Запускать лучше разово на Railway и не во время активного наплыва пользователей.

## Хранение

Пул хранится в JSON. Формат автоматически мигрирует со старого списка `file_id` на объект с версией, картинками и памятью чатов.

Пример:

```json
{
  "version": 2,
  "images": [
    {
      "id": "a1b2c3",
      "file_id": "AgACAgIAAxkBA...",
      "file_unique_id": "AQAD...",
      "added_by": 123456789,
      "added_at": "2026-04-25T13:00:00+00:00",
      "shown_count": 3,
      "last_shown_at": "2026-04-25T13:10:00+00:00",
      "likes": 1,
      "fires": 2,
      "dislikes": 0,
      "reactions_by_user": {
        "123456789": "like"
      }
    }
  ],
  "chat_history": {
    "-1001234567890": ["a1b2c3"]
  }
}
```

## Производительность

- пул читается в память один раз при запуске
- поиск картинки по `id` работает через индекс
- проверка дублей по `file_unique_id` работает через индекс
- счётчик загрузок пользователя берётся из индекса
- лимит `100` загрузок в час считается по отсортированному индексу времени, без полного прохода по пулу
- реакции нормализуются при чтении JSON
- запись JSON идёт атомарно через временный файл и компактный формат, чтобы меньше грузить Railway Volume
- глобальный анти-повтор использует быстрый выбор свежих записей без полной сортировки
- удаление картинок перестраивает индексы, поэтому `/top`, лимиты и счётчики остаются согласованными
- дуэли чистят своё состояние после завершения, а ошибки Telegram API при старых кнопках не роняют polling
- большие текстовые наборы собираются при импорте и дальше используются как обычные списки

## Структура проекта

```text
bot/__main__.py    # запуск aiogram polling и меню команд
bot/config.py      # переменные окружения и пути
bot/handlers.py    # команды, callback-кнопки и сценарии бота
bot/image_pool.py  # JSON-хранилище, рандом, реакции и индексы
bot/keyboards.py   # inline-клавиатуры
bot/texts.py       # фразы, caption-пулы, mood, достижения и народный суд

```

## Локальный запуск

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

```env
BOT_TOKEN=123456:your-token
IMAGE_POOL_PATH=data/image_pool.json
TARGET_CHANNEL_ID=
ADMIN_USER_IDS=
```

`ADMIN_USER_IDS` можно заполнить одним ID или списком через запятую:

```env
ADMIN_USER_IDS=123456789,987654321
```

Узнать свой ID можно командой `/id` в личке с ботом.

Запуск:

```bash
python -m bot
```

Проверка:

```bash
python -m compileall bot tests
python -m unittest discover
```

## Railway

В проекте уже есть:

- `Procfile` - запускает `python -m bot`
- `.python-version` - Python `3.12`

Переменные Railway:

```env
BOT_TOKEN=токен_бота
TARGET_CHANNEL_ID=
ADMIN_USER_IDS=ваш_telegram_user_id
```

Для постоянного хранения подключите Railway Volume с mount path:

```text
/data
```

Если `RAILWAY_VOLUME_MOUNT_PATH` есть, бот автоматически хранит пул тут:

```text
/data/image_pool.json
```
