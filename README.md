# kartinkomet-bot

**Telegram-бот общего склада пикч: рандом, дуэли с рейтингом, турниры, народный суд, зал славы и кладбище**

![Python](https://img.shields.io/badge/Python-3.12-3776AB?style=for-the-badge&logo=python&logoColor=white)
![aiogram](https://img.shields.io/badge/aiogram-3.20-2CA5E0?style=for-the-badge&logo=telegram&logoColor=white)
![SQLite](https://img.shields.io/badge/SQLite-WAL-003B57?style=for-the-badge&logo=sqlite&logoColor=white)
![Railway](https://img.shields.io/badge/Railway-Free-0B0D0E?style=for-the-badge&logo=railway&logoColor=white)

Бот живёт в групповом чате компании друзей. Он выдаёт случайные пикчи из общего склада, устраивает дуэли и турниры, ведёт рейтинг каждой пикчи и судит неугодных. Пополнять склад можно в личке с ботом.

Сами картинки бот не хранит: в базе лежат только Telegram `file_id`, рейтинги, реакции и статистика.

Подробное устройство: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Что умеет

| Раздел | Как работает |
| --- | --- |
| 🎲 Рандом | 70% — честная колода (без повторов, пока не показаны все), 20% — свежак за неделю, 10% — легенды зала славы |
| 🤙🏻 / 🖕🏻 | Один голос на человека, можно передумать. Под каждой пикчей кнопка «🎲 ещё» |
| ⚖️ Народный суд | Второй 🖕🏻 открывает суд на 60 секунд: «🪓 казнить / 🕊 помиловать». Казнь — при большинстве и хотя бы двух голосах «казнить». Помилованная получает неделю иммунитета. Загрузчик может ответить на карточку суда — это последнее слово |
| ⚔️ Дуэль | Две пикчи, 60 секунд. Победа и поражение двигают рейтинг Elo. Проигравшая умирает, только если её рейтинг ниже 900 или это третье поражение подряд |
| 👑 Серии | Победительница может идти дальше как чемпионка. На 3, 5 и 10 победах подряд — отдельные объявления, рекорд чата хранится |
| 🏟 Турнир | Четыре пикчи, 90 секунд, никто не умирает. Рейтинг считается попарно по голосам |
| 🏛 Зал славы | Топ-10 по рейтингу, любую можно вызвать кнопкой |
| 🕳 Дно склада | 10 худших. Любую можно отправить под суд |
| ⚰️ Кладбище | Казнённые пикчи с причиной смерти. Админ может воскресить |
| 🏆 Топы | Загрузчики, любимцы (лайки на твоих пикчах), палачи (голоса «казнить»), серии |
| 👤 Профиль | Вклад, лайки, казни, лучшая серия, титул, 30 ачивок |
| ⚙️ Админка | Health, бэкап базы, сброс статистики с подтверждением |

Тексты пишутся разными голосами: подписи — абсурд, арена — эпический комментатор, суд и топы — дерзость. Все ~1600 фраз написаны вручную, повторы в одном чате отсекаются.

## Команды

| Команда | Что делает |
| --- | --- |
| `/pic` | Случайная пикча |
| `/duel` | Дуэль |
| `/tournament` | Турнир четырёх |
| `/menu` | Живая панель: одно сообщение, которое перерисовывается на месте |
| `/top` | Топы |
| `/me` | Своя карточка |
| `/upload` | Загрузка в личке (`/upload_pidor` тоже работает) |
| `/help` | Правила |

Скрытые: `/admin`, `/health`, `/id`, `/done`, `/cancel`.

## Запуск локально

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN
.venv/bin/python -m bot
```

База создаётся в `data/kartinkomet_v2.sqlite`. Если рядом лежит старая `data/kartinkomet.sqlite` от v1, при первом старте бот перенесёт из неё всё в новый файл, а старый не тронет.

## Переменные окружения

| Переменная | Обязательна | Смысл |
| --- | --- | --- |
| `BOT_TOKEN` | да | Токен от @BotFather |
| `ADMIN_USER_IDS` | нет | ID админов через запятую. Свой ID — командой `/id` |
| `BOT_TZ_OFFSET` | нет | Смещение часового пояса от UTC для ачивок за ночные загрузки, по умолчанию `3` (Москва) |
| `DATABASE_PATH` | нет | Путь к базе v2 |
| `LEGACY_DATABASE_PATH` | нет | Путь к базе v1 для миграции |

На Railway база лежит на volume (`RAILWAY_VOLUME_MOUNT_PATH`), пути подставляются сами.

## Railway

- Сервис `worker: python -m bot` (см. `Procfile`), long polling, без вебхуков.
- Volume смонтирован в `/data`.
- aiogram намеренно закреплён на 3.20: версия 3.31 занимает в памяти примерно вдвое больше, а на бесплатном тарифе за память платят из $1 кредита в месяц.

**Откат на v1.** Вернуть `main` на коммит до v2. База v1 (`kartinkomet.sqlite`) при миграции не меняется, поэтому старая версия поднимется как была. Всё, что накопилось в v2, при этом не перенесётся обратно.

## Тесты

```bash
.venv/bin/python -m unittest discover -s tests -t .
```

Проверку миграции на настоящем бэкапе v1 можно включить переменной `KARTINKOMET_REAL_DB=/путь/к/kartinkomet.sqlite`.

## Структура

```
bot/
  __main__.py   запуск: миграция, роутеры, восстановление таймеров
  config.py
  game.py       игровой сервис: связывает базу и правила
  db/           schema.sql, repo.py (весь SQL), migrate.py (v1 → v2)
  core/         правила без Telegram: deck, elo, arena, court, achievements
  tg/           aiogram: panel, pics, arena, court, upload, admin, timers, views, keyboards
  texts/        фразы по голосам и анти-повтор
tests/
```
