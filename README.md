# kartinkomet

Telegram-бот для компании друзей: общий склад пикч, дуэли с рейтингом, турниры, народный суд и летопись всего этого позора.

## Как играть

1. Загружаешь пикчи боту в личку (`/upload`).
2. В групповом чате бот выдаёт их по `/pic` или кнопке «🎲 ещё».
3. Пикчи дерутся на арене, набирают рейтинг ⭐ и попадают в 🏛 зал славы, а слабые — на 🕳 дно и ⚰️ кладбище.
4. Не понравилась пикча — два 🖕🏻, и она идёт под суд.

## Механики

| | |
| --- | --- |
| 🎲 **Рандом** | Честная колода: повторов нет, пока не покажут все. 20% выдач — свежие загрузки за неделю, 10% — легенды зала славы |
| ⚔️ **Дуэль** | 2 пикчи одним коллажем с цветными метками A/B, голосование кнопками прямо под ним, 60 секунд. Рейтинг Elo. Проигравшая умирает, только если её рейтинг ниже 900 или это третье поражение подряд |
| 👑 **Серии** | Победительница идёт дальше как чемпионка. На 3, 5 и 10 победах подряд — объявления, рекорд чата хранится |
| 🏟 **Турнир** | 4 пикчи сеткой 2×2 с метками 1–4, 90 секунд, одна корона. Никто не умирает |
| ⚖️ **Народный суд** | Второй 🖕🏻 открывает суд на 60 секунд. Казнь — если «🪓» больше и их хотя бы два, иначе неделя иммунитета. Загрузчик может ответить на карточку суда — это его последнее слово |
| 🏆 **Топы** | Загрузчики, любимцы публики, палачи, серии |
| 👤 **Профиль** | Вклад, лайки, казни, место в топе, титул и 30 ачивок. В группе его видишь только ты |
| 🎛 **Пульт** | Одно сообщение на чат, перерисовывается на месте и показывает, что сейчас идёт |

Около 1800 фраз написаны вручную, у каждого раздела свой голос: подписи — абсурд, арена — эпос, суд и топы — дерзость. В одном чате фразы не повторяются. Бот сам ставит реакции: 🏆 на победу, 🔥 на серию, 🎉 на ачивку.

## Команды

| | |
| --- | --- |
| `/pic` | Пикча |
| `/duel` · `/tournament` | Арена |
| `/menu` | Пульт: зал славы, дно, кладбище, топы, правила |
| `/top` · `/me` | Топы · своя карточка |
| `/upload` | Загрузка в личке |
| `/help` | Правила |

Для админов: `/admin` (health, бэкап базы, сброс статистики с подтверждением, воскрешение с кладбища).

## Запуск

```bash
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env        # вписать BOT_TOKEN
.venv/bin/python -m bot
```

| Переменная | |
| --- | --- |
| `BOT_TOKEN` | Токен от @BotFather. Обязательна |
| `ADMIN_USER_IDS` | ID админов через запятую. Свой ID — `/id` |
| `BOT_TZ_OFFSET` | Часовой пояс от UTC для ачивок за ночные загрузки. По умолчанию `3` |

База — один файл SQLite: `data/kartinkomet_v2.sqlite`, на Railway — в volume. Картинки не хранятся, только Telegram `file_id`.

**Railway:** worker `python -m bot` (см. `Procfile`) и volume. Бот укладывается примерно в 100 МБ памяти, поэтому aiogram закреплён на 3.20: 3.31 занимает вдвое больше.

**Переезд с v1:** если рядом лежит старая `kartinkomet.sqlite`, при первом старте бот перенесёт из неё всё в новый файл. Старый файл не меняется, так что откат — просто предыдущий коммит.

```
bot/
  core/     правила без Telegram: колода, Elo, арена, суд, ачивки

  game.py   связывает правила и базу
  tg/       обработчики aiogram, карточки, клавиатуры, таймеры
  texts/    фразы
tests/      правила, сервис, миграция, тексты, клавиатуры, сквозные сценарии с фейковым Telegram
```
