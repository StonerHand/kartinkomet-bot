# kartinkomet v2 — дизайн

Дата: 2026-10-12. Статус: согласовано в чате, реализуется в ветке `v2`.

## Цель

Переписать бота для одной компании друзей: чистая структура, новые механики (рейтинг, серии, суд 2.0, ачивки), одна живая панель вместо спама в чат, смешной рукописный текст с матом. Все текущие данные сохраняются. Хостинг прежний: Railway Free, long polling, SQLite на volume.

Вне рамок (вторая волна): очки игроков, авто-события по расписанию, публикация в канал.

## Структура

```
bot/
  __main__.py      запуск, миграция, роутеры, восстановление таймеров
  config.py
  db/schema.sql    схема v2
  db/migrate.py    v1 → v2, новый файл, старый не трогаем
  db/repo.py       весь SQL
  core/            логика без Telegram: deck, elo, arena, court, achievements
  tg/              aiogram-слой: middleware, panel, pics, arena, court, upload, admin, keyboards, timers, send
  texts/           фразы по голосам + pick.py (анти-повтор)
```

Правила: `core` не импортирует aiogram; SQL только в `repo`; активные бои и суды хранятся в БД и переживают рестарт; пул в память не грузится.

## Данные

Пикчи не удаляются физически: `status` = `alive` | `executed` | `deleted`, плюс `removed_at`, `removed_reason`.

Таблицы: `users`, `pics` (rating, games, wins, losses, loss_streak, best_streak, shown_count, likes, dislikes, immune_until), `reactions`, `deck_seen`, `battles`, `battle_entries`, `battle_votes`, `courts`, `court_votes`, `achievements`, `meta`.

Миграция: если `kartinkomet_v2.sqlite` нет, а v1-база есть — создать v2 из v1 в одной транзакции, сверить количество пикч/реакций/юзеров, иначе упасть. Стартовый рейтинг: `1000 + clamp(15·(likes − dislikes), −150, 150)`. `image_chat_history` → `deck_seen`. Счётчики дуэлей/турниров → `meta`. `documents` и таблицы шуток не переносятся.

## Алгоритмы

**Рандом.** Кубик: 70% колода, 20% свежак (загружено ≤ 7 дней назад), 10% легенда (топ-50 по рейтингу, ≥ 3 боя). Кандидаты всегда — живые пикчи, не показанные в этом чате в текущем круге (`deck_seen`). Пустая корзина → колода. Колода пуста → очистить `deck_seen` чата (новый круг). Показ записывается в `deck_seen`, `shown_count`.

**Elo.** K = 32 при < 10 боях, иначе 16. Дуэль — стандартно, ничья = 0.5. Турнир — попарно по числу голосов, K/3. Ноль голосов — рейтинг не меняется, никто не умирает.

**Дуэль насмерть только для слабых.** Проигравшая казнится, если после боя её рейтинг < 900 или `loss_streak` ≥ 3. Иначе только теряет рейтинг.

**Серии.** Победитель получает кнопку «👑 Чемпион дальше», следующая дуэль с ним, серия +1. Ничья — серия держится. Поражение — серия сгорает. Хранится `best_streak` пикчи и рекорд чата в `meta`. На 3/5/10 особые фразы.

**Суд 2.0.** Повод: второй 🖕🏻 под пикчей или кнопка «⚖️ Под суд» на дне склада. Карточка с таймером 60 с: «🪓 Казнить / 🕊 Помиловать». Загрузчик может ответить на карточку текстом — это последнее слово (до 300 символов). Казнь при большинстве и ≥ 2 голосах «казнить». Иначе помилование и иммунитет 7 дней. На одну пикчу — один активный суд.

**Ачивки.** ~30 штук, проверяются после событий: загрузки (ступени), ночные загрузки, полученные лайки/дизлайки, казни твоих пикч, голоса «казнить» (палач), голоса «помиловать» (адвокат), серии твоих пикч, твоя пикча в зале славы.

## Экраны

Одна живая панель на чат (`/menu`, `/start`), перерисовывается на месте, у экранов «⬅️ Назад». Повторный `/menu` удаляет старую панель.

Главная: 🎲 Пикчу · ⚔️ Дуэль · 🏟 Турнир / 🏛 Зал славы · 🕳 Дно склада · ⚰️ Кладбище / 🏆 Топы · 👤 Я · 📥 Загрузить / ⚙️ Админка (только админам).

- Зал славы: топ-10 по рейтингу, «👀 №N» присылает пикчу, рекорд серии.
- Дно склада: 10 худших (≥ 3 боя), «⚖️ Под суд».
- Кладбище: сколько казнено, последние 5 казней; админ — «🕊 Помиловать».
- Топы: вкладки 📥 Загрузчики / ❤️ Любимцы / 🪓 Палачи / 🔥 Серии.
- Я: вклад, лайки, казни, лучшая серия, титул, ачивки, следующая цель.
- Админка: health, бэкап, сброс статы с подтверждением.

Под пикчей: `🤙🏻 N · 🖕🏻 N · 🎲 ещё`. Дуэль: альбом + карточка с таймером. Турнир: альбом из 4 + карточка. Загрузка — только в личке, одна карточка прогресса.

Команды: `/pic /duel /tournament /menu /top /me /upload /help`, `/upload_pidor` — алиас.

## Тексты

Голоса: подписи — абсурд; арены — эпос; суды, топы, профиль — дерзость; меню и ошибки — сухой стёб. Мат разрешён. Всё рукописное, правильный род, без генераторов. Объёмы: подписи 500, свежак/легенда по 40, дуэль 5×60, серии 3×20, турнир 4×50, суд 5×40, топы 80, ачивки 30, служебное ~150. Анти-повтор: фраза не повторяется в чате, пока не прошла половина пула.

## Проверки и выкатка

Юнит-тесты на `core`, тест миграции на копии реальной базы, тесты `tg` на длину `callback_data` ≤ 64 байт и маршрутизацию кнопок, тесты текстов (уникальность, HTML, длины). Ручная проверка на тестовом боте локально. Выкатка: бэкап → мерж `v2` в `main` → Railway деплоит → проверка логов. Откат: старый коммит, старая база нетронута.
